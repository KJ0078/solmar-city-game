Solmar City is an original open-world crime game that plays offline in a desktop browser: explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police, and work through a story of missions.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. To hand the game in as an entry, run `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
